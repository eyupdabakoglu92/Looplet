# F00-QA-VISUAL evidence (QA, 2026-09-21)

Independent runtime evidence for `../qa.md`. Revision under test: commit 78b22e3 content (app tree `d9709ad858e4eda876f00e664281fa208409f6ca`, unchanged at HEAD a499e5d), iOS Simulator 18.6.

* `qa-iphone16-tiles-640.png`, `qa-iphone16-controls-1280.png` — QA's own gallery frames on iPhone 16 (393x852, stored at 50 %). `qa-iphone16e-sheet.jpg`, `qa-iphone16promax-sheet.jpg` — QA's own five-frame sheets on 16e (390x844) and 16 Pro Max (440x956).
* `qa-edge-cases-iphone16.jpg` — the QA probe's edge cases at default text size (two-digit loop nodes, long labels, moves 0-100, stars 0-3, undo quota 0-3, three-digit stats, Turkish capitals at three tile sizes, a five-line glass card).
* `qa-dynamic-type-1.65x.jpg` (accessibility-medium, the `platform.md` §14 floor) and `qa-dynamic-type-3.1x.jpg` (accessibility-extra-extra-extra-large) — the gallery and the probe under OS text size; `dynamic-type-sweep.txt` — overflow table over nine sizes for the gallery and the probe.
* `semantics-gallery-iphone16.txt` — the real gallery's runtime semantics tree (92 nodes) with sizes and flags; `box-sizes-edge-iphone16.txt` — RenderBox sizes of the components in the probe.
* `src/` — the probe and helpers. **The probe is not part of the repository build**: it imports the delivered layer as a package and is built from `app/` with `flutter build ios --simulator --debug -t <path>/qa_probe_main.dart`; modes are chosen by a file in the app container's `tmp/` (`probe_mode`: `edge`, `gallery`, `press`, `nopress`; `probe_offset`, `gallery_offset`). `runprobe2.sh` launches a mode and collects `QAPROBE` log lines and a screenshot; `pressrun.sh` holds a synthetic pointer-down on a `LimePill` (compare the pill width to the `nopress` frame: 0.978 with Reduce Motion off, 1.000 on); `bmp.py` reads pixels (`sips -s format bmp`) and computes CIEDE2000; `summ.py` summarises the text-size sweep. Text size: `xcrun simctl ui <udid> content_size <category>`; Reduce Motion: `xcrun simctl spawn <udid> defaults write com.apple.Accessibility ReduceMotionEnabled -bool true|false` (both restored after the run).
